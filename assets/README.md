# Assets — Pixel Observatory / Autonomy Trial v0.3.0

Los sprites, tiles, bitmap font e iconos de esta entrega se dibujaron específicamente para este prototipo mediante artefactos PNG de baja resolución y escalado por vecino más cercano. No se empaquetaron fuentes tipográficas ni packs de terceros.

- `sprites/`: cinco especies del Piso 1 y utilería de minería/cristal.
- `tiles/`: seis superficies de galería.
- `ui/font_5x7.png`: atlas bitmap de 5×7 con caracteres listados en `font_chars.txt`.
- `icons/`: icono clásico, foreground/background adaptativos de Android, icono monocromo y recurso del splash.

Las criaturas representan fichas del catálogo de bestiario v0.1; no afirman que haya entidades biológicas activas ni spawns en el mundo runtime. El material visual de referencia se conserva en `docs/reference/visuals/`.
