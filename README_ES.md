# World Laboratory — Master Map Blockout 0.2.0

Proyecto Godot 4.7.2 para el primer blockout del reino fantástico y el piso 1 de la Torre/Mazmorra.

## Abrir
1. Descomprime el ZIP.
2. Abre Godot 4.7.2 Standard.
3. Importa la carpeta del proyecto (la que contiene `project.godot`).
4. Ejecuta `scenes/main.tscn` o pulsa F6/F5.

## Controles
- `ENTER`: alternar vista exterior / piso 1.
- `ESC`: volver a la vista exterior.

## Qué contiene
- Mundo exterior de una sola raíz: pueblo, carreteras, río, campos, muralla, bosque interior y torre.
- Torre exterior monumental.
- Dominio interior independiente del piso 1, con 12 cámaras diferenciadas y corredores de varias anchuras.
- Vetas minerales visibles y zona segura marcada.
- Cámara isométrica ortográfica.

## Importante
Este ZIP es un blockout geométrico inicial, no un juego terminado ni una compilación Android validada. No contiene personajes, combate, IA, NavMesh final, arte final, minería ni sistema de hogares. El documento de diseño está en `docs/MASTER_MAP_BLOCKOUT_0.2.0_ES.md`.

La rama/repositorio base del proyecto System-Reactor mantiene su propia autoridad de arquitectura y SR-01 a SR-07. Este paquete es una entrega de implementación espacial para revisar e integrar, no una sustitución de los documentos normativos.
